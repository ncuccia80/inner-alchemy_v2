# UX and Design Specification

## Design Pillars

1. Game first
2. Beautiful and contemplative
3. No punishment
4. Curiosity-driven
5. Reflection is optional
6. Premium is additive later, not punitive

## Visual Direction

- Dark navy/indigo background
- Soft gradients
- Emotion orbs or chips
- Subtle glow effects
- Smooth discovery burst
- Serif display font optional
- Sans-serif body font
- Minimal UI chrome

## Navigation

MVP tabs:
- Lab
- Library
- Profile

Future:
- Journeys
- Reflect

## Lab Screen

Components:
- Header with progress
- Main combine area
- Emotion tray
- Combine button
- Error/nudge area

Interaction:
1. User selects first emotion.
2. User selects second emotion.
3. User taps Combine.
4. Resolver checks recipe.
5. If valid, show discovery modal.
6. If invalid, show gentle copy: "No new state emerged."

## Discovery Modal

Show:
- "New Discovery"
- Emotion name
- Tier name
- Insight text
- Continue Exploring button

Animation:
- Fade backdrop
- Scale modal in
- Glow burst for new discovery

## Library

Grid or list of discovered emotions.

Each detail page should show:
- Emotion name
- Insight
- Recipe
- Tier
- Tags

Undiscovered emotions:
- Show as silhouettes or ??? entries
- Do not reveal recipes unless intentionally designed later

## Settings/Profile

Include:
- Discovery count
- Reset progress
- Disclaimer
- Placeholder premium status
