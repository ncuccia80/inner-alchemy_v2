# MVP Scope

## Goal

Build the smallest playable version of Inner Alchemy that validates the core discovery loop.

The central question:
Can a person combine emotions for 15-20 minutes and enjoy discovering new emotional states?

## MVP Content

### Tier 0 - Starting Primitives

- Love
- Fear
- Anger
- Sadness
- Joy
- Disgust
- Trust
- Anticipation

### Tier 1 - Initial Discoveries

Use the Tier 1 combinations in data/emotions.json and data/recipes.json.

Minimum target:
- 25 Tier 1 discoveries

### Tier 2 - Starter Complexity

Include only 10 Tier 2 states.

Use only these modifiers for MVP:
- Memory
- Safety
- Time

Awareness, Meaning, and Power can exist in the data but should be hidden or reserved.

## MVP Screens

### 1. Onboarding

Simple first-run explanation:
"Combine emotions to discover new states of mind."

Include:
- One forced tutorial combo: Fear + Love = Jealousy
- Not-therapy disclaimer

### 2. Lab

Main play area.

Required:
- Emotion tray
- Selected combination slots or drag canvas
- Combine button
- Result feedback
- Progress counter

### 3. Discovery Modal

Shows:
- New discovery label
- Emotion name
- Tier
- Insight text
- Continue button

### 4. Library

Shows:
- Discovered emotions
- Locked silhouettes for undiscovered items
- Detail view with recipe and insight

### 5. Settings/Profile

Required:
- Reset progress
- Disclaimer
- Placeholder for future premium

## Out of Scope

Do not build:
- Paid subscriptions
- Login
- Cloud sync
- AI-generated emotions
- Journaling
- Audio reflections
- Social features
- Therapist dashboard
