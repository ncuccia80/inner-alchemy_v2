# Emotional Ontology

## Design Principle

Inner Alchemy uses a psychologically coherent emotional ontology disguised as a casual discovery game.

The player should not need to understand theory. The system should simply feel intuitive.

## Tier 0 - Emotional Primitives

These are the emotional atoms of the game:

1. Love
2. Fear
3. Anger
4. Sadness
5. Joy
6. Disgust
7. Trust
8. Anticipation

## Tier 1 - Emergent Emotions

Tier 1 combines two primitives.

Examples:
- Fear + Love = Jealousy
- Love + Sadness = Grief
- Love + Joy = Gratitude
- Fear + Anticipation = Anxiety
- Fear + Disgust = Shame
- Anger + Sadness = Resentment
- Joy + Trust = Contentment

## Tier 2 - Complex States

Tier 2 combines Tier 1 emotions with modifiers or other emotional states.

MVP modifiers:
- Memory
- Safety
- Time

Future modifiers:
- Awareness
- Meaning
- Power
- Identity
- Choice
- Values

Examples:
- Shame + Memory = Humiliation
- Resentment + Time = Bitterness
- Anxiety + Time = Chronic Anxiety
- Anxiety + Safety = Stabilization
- Grief + Time = Mourning
- Shame + Safety = Self-Compassion

## Tier 3 - Future Premium Layer

Do not build in MVP.

Future examples:
- Healing
- Integration
- Wholeness
- Agency
- Integrity
- Self-Leadership
- Purpose
- Flow
- Flourishing
- Transcendence

## Content Tone

Insight copy should be:
- Short
- Human
- Poetic but clear
- Non-clinical
- Not preachy
- Screenshot-worthy

Bad:
"Jealousy is an attachment-related affective state associated with perceived relational threat."

Good:
"Fear of losing what we cherish."
